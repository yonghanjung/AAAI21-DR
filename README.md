# AAAI21-DR

This is a demonstration of the implementation of 

> [**Estimating Identifiable Causal Effects through Double Machine Learning**] Y.Jung, J. Tian, E. Bareinboim. AAAI-21. In *Proceedings of the 35th AAAI Conference on Artificial Intelligence, 2021.* (Acceptance rate: 21%) [pdf](https://causalai.net/r69.pdf)

written by [Yonghan Jung](https://sites.google.com/view/yonghanjung). 



A code for demonstrating DML-ID for Napkin and planid is here. For each folder ```x in {napkin, planid}```, 

* ```x_real_main.R``` is a main file. 
* ```x_real_data.R``` is a data generating process. 

In ```napkin``` folder, ```napkin_real_vDML.R``` is an implementation. In ```plainid```, ```planid-real-DR.R``` is an implementation.
